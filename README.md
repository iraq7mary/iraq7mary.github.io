# iraq7mary.github.io

Yi Waiwai (易歪歪) Unix timestamp and time-zone converter - a pure client-side web tool that converts Unix timestamps to dates and back and shows the current time across common zones (Beijing, UTC, US Eastern/Pacific, London, Tokyo, Jakarta, Sydney), for cross-border e-commerce customer service. 12 languages.

Live: https://iraq7mary.github.io/
